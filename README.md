# Menentukan-Nilai-Maksimum-X-Berdasarkan-Bilangan-dan-Nilai-Tambahan
Program ini menghitung nilai maksimum yang bisa dicapai dari sebuah bilangan bulat num dengan penambahan nilai t, ditambah bonus berdasarkan apakah num genap atau ganjil:  Jika num genap, tambahkan 1  Jika num ganjil, tambahkan 2
